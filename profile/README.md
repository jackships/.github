# Jack Ships

One indie maker shipping small web tools and iOS apps. These repos are the useful bits pulled out of them: open data, tiny zero-dependency libraries and CLIs.

| Repo | What it is | Comes from |
|---|---|---|
| [ai-search-readiness](https://github.com/jackships/ai-search-readiness) | CLI: can ChatGPT, Perplexity and Claude crawlers reach and read your site? | [Citelane](https://citelane.app) |
| [photo-to-coloring-page](https://github.com/jackships/photo-to-coloring-page) | Photo → printable coloring page in the browser ([demo](https://jackships.github.io/photo-to-coloring-page/demo/)) | [Linecraft](https://linecraft.page) |
| [conversation-topics](https://github.com/jackships/conversation-topics) | 910 conversation, debate, ESL and writing topics as open JSON | [Random Topics](https://randomtopics.app) |
| [promo-breakeven](https://github.com/jackships/promo-breakeven) | Discount and ad math: break-even ROAS/CPA, max discount, BOGO | [Evenline](https://evenline.app) |
| [product-video-specs](https://github.com/jackships/product-video-specs) | Product video upload limits for Shopify, TikTok, Reels, Shorts, Amazon | [Folra](https://folra.video) |
| [ai-video-qc](https://github.com/jackships/ai-video-qc) | One ffmpeg pass that catches broken generated videos | [duet.room](https://duetroom.com) |
| [puppy-potty-schedule](https://github.com/jackships/puppy-potty-schedule) | Puppy potty intervals by age and a daily schedule | [Puppy Routine](https://puppyroutine.app) |
| [aion2-data](https://github.com/jackships/aion2-data) | Aion 2 rift schedules, resets, servers, classes, Daevanion boards | [Aion2 Atlas](https://aion2atlas.app) |
| [workout-plan-schema](https://github.com/jackships/workout-plan-schema) | JSON Schema + validator for workout plans | Movo |
| [spaced-repetition-lite](https://github.com/jackships/spaced-repetition-lite) | SM-2, Leitner and an exam-date-aware scheduler | Pip |
| [zh-schedule-parser](https://github.com/jackships/zh-schedule-parser) | Chinese & English schedule sentences → dates and repeat rules | Lili |
| [coffee-brew-ratios](https://github.com/jackships/coffee-brew-ratios) | Brew ratios, grind sizes, water temps + calculators | Cuppa |

Writing about what worked (and what didn't) on [dev.to](https://dev.to/jackships) and [Hashnode](https://hashnode.com/@jackships).
